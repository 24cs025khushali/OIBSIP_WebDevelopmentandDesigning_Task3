## 📖 Project Overview

The Temperature Converter Website is a responsive web application developed using HTML, CSS, and JavaScript. The application allows users to convert temperature values between different units such as Celsius (°C), Fahrenheit (°F), and Kelvin (K) instantly and accurately.

The primary goal of this project is to provide an easy-to-use interface where users can perform temperature conversions in real time while improving their understanding of frontend web development concepts.

## 🌡 Temperature Conversion Formulas

### Celsius to Fahrenheit

°F = (°C × 9/5) + 32

### Fahrenheit to Celsius

°C = (°F − 32) × 5/9

### Celsius to Kelvin

K = °C + 273.15

### Kelvin to Celsius

°C = K − 273.15

### Fahrenheit to Kelvin

K = (°F − 32) × 5/9 + 273.15

### Kelvin to Fahrenheit

°F = (K − 273.15) × 9/5 + 32
